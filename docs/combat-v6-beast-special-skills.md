# 灵兽特殊技能首轮接入

2026-10-05。用户确认只复刻融合度高的《梦幻西游》电脑版普通召唤兽特殊技能，数值沿用原版，仅调整修仙文案；原始神兽技能暂不接入。观照万象按用户要求取消物种专属和战斗回合数门槛；出奇制胜取消狐族限制，所有技能获得后均不绑定物种。七项特殊技能暂不开放传承灵印。当前技能配置修订 18，物种配置修订 14。

## 本轮技能

| 出生来源 | 游戏技能／ID | 原版来源 | 实施效果 |
| --- | --- | --- | --- |
| 谛听 | 观照万象／`beast.all-seeing` | 谛听／观照万象 | 首回合可用，可通过融合继承至其他物种；随机排序并逐个使用已学主动攻击技能，不包含自身、被动或纯辅助技能。冷却 150 回合；子技能各自支付正常费用并接受冷却、控制和资源校验。无攻击技能时不可发动，目标离场后重新选敌；死亡、无法施法或资源不足时停止 |
| 朱厌 | 摧山／`beast.mountain-breaker` | 大力金刚／力劈华山 | 耗法力＝等级＋20；本次命中增加等级×2＋10；物理攻击差正值最多取等级×8，双方攻击与目标防御共同决定伤害，保留防御、修炼、必杀和波动结算 |
| 獬豸 | 善恶有报／`beast.karmic-retribution` | 律法女娲／善恶有报 | 耗法力＝等级＋10；必中。70%恶报，普通物理伤害×2、必杀×3；30%善报，恢复目标普通物理伤害的50%、必杀恢复100%。善报不触发伤害、保护、反击或吸血 |
| 蜃蚌 | 凝光炼彩／`beast.radiant-barrier` | 妙华天女／凝光炼彩 | 入血伤害后25%概率获得其50%的护盾，凝光护盾累加至最大气血30%上限；每回合末剩余值×85%，不设固定到期回合。支持直接、派生和周期伤害；纯护盾吸收不生成新盾，致命伤不生成新盾 |
| 麒麟 | 瑞气盈身／`beast.auspicious-vitality` | 广目巡守／净台妙谛 | 气血上限额外增加完整体质×成长×2，展示与战斗使用同一面板投影，不改永久加点或体力资质 |

七项技能均设置 `book: false`，不注册普通或上品传承灵印，野外、幻境、秘境灵印池不含这些条目；市场、挂机、讨伐的独立池也不开放。现有67种普通／上品灵印保持原概率、数量与单项权重，秘境上品奖励期望为约0.1005枚／趟。特殊技能保留高级技能标记，通过对应出生候选或现有融合流程获得；物种仅决定出生来源，不限制继承后的生效。捕捉、初领和洗炼采用新的出生候选，已有个体技能、加点、资质和成长不重抽。

## 数值出处与证据边界

公开说明、维护公告与玩家实验分开记录，避免把隐藏公式的推定当成官方披露。本轮没有自行调整已知倍率或概率来平衡强度。

- 观照的随机顺序、冷却与费用中断参照[2019年技能测试](https://xyq.yzz.cn/focus/201912/1597605.shtml)。只有物种专属、战斗回合数门槛由用户明确取消。
- 摧山耗蓝参照[2013年调整公告转载](https://xyq.17173.com/content/2013-10-21/20131021215611261_all.shtml)，攻击差上限参照[2014年维护解读](https://xyq.17173.com/content/2014-09-23/20140923092736399_2.shtml)，临时命中参照[力劈测试中的技能公开说明](https://ol.3dmgame.com/gl/226015.html)。完整计算采用常见玩家公式 `(己方物攻 − 敌方物防 + min(己方物攻 − 敌方物攻, 己方等级 × 8)) × 系数`，己方物攻较高时系数1.5，否则0.5，随后接入当前修炼与物理结算。**完整公式存在不同玩家版本，攻击相等时的0.5分支是本轮明确的工程边界，尚无原版实测确认。**
- 善恶的70/30来自[100回合玩家测试](https://xyq.17173.com/content/04302022/131910455.shtml)，并非官方已公布固定概率。普通、必杀伤害与善报恢复参照[2011年实测](https://xyq.17173.com/content/2011-10-01/20111001090344032%2C1_1_all.shtml?_platform=PC)，耗蓝参照[善恶永动机说明](https://xyq.yzz.cn/focus/202006/1613382.shtml)。沿用本游戏修炼、取整和属性投影，不声称复刻未公开的底层取整顺序。
- 凝光25%与50%参照[技能介绍](https://xyq.yzz.cn/focus/201902/1554152.shtml)，上限30%、每回合末85%、无限持续参照[研发交流报道](https://ol.gamersky.com/news/201703/879128.shtml)和[2017年维护转载](https://www.9game.cn/news/1686162.html)。**凝光反复触发的叠加方式、伤害是否包括已有盾吸收量未找到原版实测；本轮采用入血伤害基准与限额累加。**其他既有护盾不因本轮改为梦幻的通用上限和衰减。
- 瑞气公式参照[净台与凝光原始发布](https://news.17173.com/content/12092018/134422196.shtml)。体质包含基础与已分配体质，不拿体力资质代替。
- 嗜血的神佑触发、半伤、不耗法力参照[电脑版技能专题](https://xyq.yzz.cn/special/2021xzlp/)，每回合最多一次参照[2009年发布表](https://games.sina.com.cn/o/z/xyq/2009-05-15/1507330069.shtml)。
- 出奇参照[2022年发布专题](https://xyq.yzz.cn/special/2022pfcz/)与[玩家测试](https://xyq.yzz.cn/skill/202201/1660231.shtml)。原版狐族条件已按用户要求取消；保留后续回合入场、首法＋25%，未加“只入场当回合”限制。**延后施法保留、同只灵兽召回后再次入场重置，是按公开文字实施的边界，未找到专项实测。**观照编排动作自身不消费首法，真实子法术照常消费。

须弥真言、天狐之舞及原始神兽特殊技能均未加入本轮。

## 实现与验证

核心只增加通用攻击技能调用、入场／施法计数、致零记录、最终必杀倍率、物理数值治疗、承伤通知及护盾衰减能力，不识别灵兽物种或技能ID。技能定义与倍率位于内容层，摧山公式及瑞气面板位于规则层；串行调用、护盾和入场计数保存在战局快照并使用种子随机数。

纯领域测试覆盖连续施法的顺序、资源不足、控制、死亡、改目标、整法连击与冷却；技能测试覆盖出生／投影、特殊技能灵印关闭与伪造ID拒绝、善恶分支与必杀、凝光实际掉血基准、上限取整、衰减、派生与周期伤害，追击含神佑、非递归及隐身／灵觉边界，摧山命中只作用于自身技能，出奇跨物种投影、无物种标记生效及与观照子法的首次整法联动。自动战斗支持主动特殊技；连续施法无法支付当前可发动攻击组合时，采用保守估值，优先可支付的单项攻击或普攻，手动观照仍按正常随机序列执行并接受中断。

本轮使用项目固定 pnpm 10.34.6 完成验证：

- `pnpm run test`：253 个文件、2576 项测试全部通过，覆盖核心、技能、物种与奖励池，以及受新承伤钩子影响的宗门 JSON Schema 一致性。取消物种门槛及关闭灵印后的定向回归为16个文件、189项通过。
- `pnpm run lint`：全仓 ESLint 与 API Oxlint 通过。
- `pnpm run typecheck`：全部包、API、Web 与维护工具类型检查通过；另以严格 TypeScript 参数单独检查两个特殊技能测试文件，通过。
- `pnpm run build`：八个构建任务通过，包含前端与 API。
- `git diff --check`：通过。新增测试格式化后及秘境奖励旧断言修正后另做定向 ESLint，通过。

首轮初次回归时，奖励池版本变化使旧测试固定种子抽中合法的额外图纸，已将通关总数断言校正为1件基础奖励加至多1件额外奖励；保留完整对象确定性与非法等级校验，没有调整奖励算法或概率来匹配种子。

按项目数据层规范只读核对专用本地数据库：库存、邮件、系统邮件活动、拍卖、声望商店、宗门商店和物品库中均无七种已关闭灵印的引用，无需清理本地数据。已有灵兽的特殊技能事实继续正常解析、投影和融合，不依赖灵印注册。

未做浏览器实战或服务端培养流程的端到端验收；本轮验证范围为纯战斗／培养规则、配置完整性与前后端构建。已有个体与数据库结构未迁移，少数原版隐藏机制的证据边界仍以上一节为准。
