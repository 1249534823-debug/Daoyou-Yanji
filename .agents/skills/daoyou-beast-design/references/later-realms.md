- 已确认名单、形态、炼虚出生表；用户授权补齐后续资质、成长与出生技能并实施。
- 下表数值、出生表、栖息地与正式ID已落入配置；首批十八种不变，不重抽存量。
- 合体及以上为稀有异兽；普通出生、捕捉与变异规则保持共用。平衡尚需长期实战观察。

后续优先选用耳熟能详、名字本身能形成画面的异兽。用户提供的异兽图用于选种参考；传统异兽、神兽名称与轮廓可借鉴，具体生态、天赋和数值属于项目改编，不将其表述为原典设定，也不从插画直接推导战斗能力。

## 2. 炼虚形态与生态

| 物种 | 形态、栖息地与习性 |
| --- | --- |
| 鸣蛇 | 细长身躯覆暗赭细鳞，背侧两对宽薄翼膜，静伏时贴身如崖壁枯藤。起飞前昂首辨风，振翼发出金石般鸣声；腹鳞附着裂渊岩面，凭翼膜感知乱流，在短暂平稳的气流中捕猎。与水生墨蛟区分，鸣声不附赠控制机制 |
| 蜃蚌 | 两片层叠灰白巨壳，外侧粗粝，内侧泛青紫珠光；开壳露出肉裙与凝聚水珠，闭壳缓吐湿雾。伏居灵液暗河，以肌足缓慢移动、滤取水中灵息，受扰收壳后吐出水流。厚壳保护肉身，灵息赋予御法；湿雾为生态表现 |
| 琥珀蝉 | 约一掌长，蜜色胸腹，翅薄如旧琥珀，金色细脉清楚；幼体在灵液滋养的古木中蛰伏多年，从树脂封结处蜕出，空壳保留足爪与翅根。以蜕生解释涅槃天赋，为可正常接受回血的活体异虫，与冥灯蝶的灵魂体区分 |
| 獬豸 | 厚毛独角、坚实蹄足，身躯近壮硕羊兽，肩颈披长鬃，粗直额角有层叠生长纹。栖居裂渊上层断石高地，角根与蹄足敏锐感知岩层震动；遇敌侧身沉肩，再以独角迎击。厚实肩颈对应招架，感官对应灵觉 |

- 用户明确要求琥珀蝉取消必带，并将涅槃重生升级为高级版；獬豸取消必带，原高级招架移入候选。两项高级候选均以 50% 出生，是本轮明确确认的例外，不自动扩展为全部物种高级候选规则。

- 鸣蛇不成套附赠连击与噬血。蜃蚌保留高级御法对自身物伤的代价，灵法反震为概率效果；水击不自动升级群法。獬豸保留蛮力面对铁骨目标的既有物伤代价，解厄为回合结束解除可驱散异常。
- 必带和候选获得后均可被传承灵印覆盖，技能数量与资质、成长独立。

## 4. 场景衔接与未录取方案

- 生态锚点为玄黄裂渊、九幽冥海、太虚天关、飞升台·万劫雷狱；主地图已有这些地点不代表已经配置野外捕捉池。合体可沿九幽冥海周边安排雾林、地火岸、沉礁和古战场，具体捕捉节点见第6节。
- 上一版合体的蠃鱼、吞舟鲸、冥海巨螯全部撤下；悬丝蛛、夔、劫余虫明确不录取，不作为当前名单或换名回填。
- 帝江、龙马仅为备选，不计入本轮十六种；本版优先采用白泽、穷奇、饕餮，以及应龙、金乌、麒麟、谛听等熟悉的异兽、神兽。
- 采用现有技能体系表达生态。白泽不新增识破全部机制的能力，饕餮不新增吞噬装备，应龙不因名称自动掌握额外规则；新增机制须作为独立设计讨论。

## 7. 融合与验证边界

融合继续采用双亲均值乘独立随机系数，成长兜底改为1.500；取消首批十八种出生最大值形成的资质玩法上限，仅保留各项100000的结构边界。平均系数小于1不能保证反复选优不会增长。详见[融合规则](../../../../docs/combat-v6-beast-fusion.md)。

早期炼虚草案曾以105、120、180级及六种可比加点核对432次面板计算，均为有限正值；不含技能和实战胜率。这份记录不替代本次实施验证。当前测试覆盖新物种生成、技能全集、地图引用、逐位置稀有概率、变异独立性及融合边界；具体执行结果记录于本轮交付文档。
