# 天灵秘境独立场景与多项奖励

## 行为

- 造化导航中蜃楼幻境之后新增天灵秘境，路径 `/game/secret-realms/tianling`。
- 普通探秘地图不再内嵌秘境。独立页面先显示奖励，明确点击后才开始；其他历练需先处理完。
- 后台秘境管理通过独立抽屉配置最多20项奖励。支持天灵丹、灵气、灵石、修为、声望、六维基础属性及已发布道具库物品。
- 入场时在事务中解析并保存奖励快照；后续管理员编辑、道具下架和关闭秘境不影响已经入场的奖励。
- 沿用两名守卫和首领全部击败、每日次数、断线恢复、幂等结算。失败或撤退不发通关奖励。
- 资源按既有上限结算；属性只接受六个基础属性，不接受派生战斗属性。数量校验、乐观版本锁与管理员审计保留。

## 迁移与回滚

`0038_secret_realm_rewards.sql` 仅给秘境设置和审计表增加可空 rewards JSONB。旧配置为空时默认天灵丹1颗，保留既有开启状态。

发布脚本 `scripts/deploy-realm-rewards.py` 检查上一迁移0037的哈希、备份数据库、事务执行0038并记录Drizzle日志，然后切换构建。准备检查失败会回退应用与静态文件；不自动还原线上数据库，保留兼容的新增字段。
