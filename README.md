## 用户数据处理说明

账号与游戏运行需要处理邮箱、认证凭据或 OAuth 账号标识、登录会话、角色、物品、聊天、操作记录及战报。Web 服务器保留必要的访问与错误日志（包括 IP、请求路径等），用于安全与故障排查。AI 生成所需的角色设定、故事或物品描述会发送至本站配置的模型服务商；请勿在生成内容中填写敏感个人信息。

跨服功能默认不向其他站点开放角色切磋；玩家主动开启后，互信站点可以读取必要的角色公开摘要与战斗构筑、交换邀战与战报。账号密码、验证码、登录 Cookie、服务器私钥不共享。除账号、游戏、安全排查及上述 AI 生成和自愿跨服所必需的数据外，当前检查未发现额外的营销追踪或信息采集模块。
